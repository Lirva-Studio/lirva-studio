# Lirva Studio preview
Run npm ci followed by npm run dev to preview the combined site. For the built site, run npm run build and npm run preview. The dist folder contains the prebuilt frontend.

The original member password opens the encrypted member tools. Saved device access is specific to the browser and site address. Individual email accounts and their category permissions require the included server with MEMBER_ACCOUNTS_JSON configured. A static host serves the original password flow and public pages. The source archive contains no production member credentials.
